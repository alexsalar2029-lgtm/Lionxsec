فروشگاه چهارزبانهٔ اشتراک دیجیتال با طراحی شیر چشم‌آبی، پنل مدیریت محصولات و کیف پول‌ها، حداقل سفارش ۵ عدد از هر محصول، و قیمت USDT.

پرداخت با Litecoin یا USDT روی BEP-20 انجام می‌شود. بررسی پرداخت و تحویل از طریق [@link_Lion](https://t.me/link_Lion) کاملاً دستی است.

## امکانات جدید

- افزودن محصول جدید، انتخاب لوگوی آماده یا آپلود لوگوی PNG/JPG/WebP از سیستم؛ حداکثر ۳ مگابایت.
- محاسبهٔ زندهٔ مبلغ انتخاب‌شده روی کارت محصول و جمع ردیف و کل سبد هنگام تایپ تعداد.
- پنل آموزش ویدیویی: آپلود MP4/WebM تا ۲۵۰ مگابایت، عنوان و توضیحات چهارزبانه، انتشار و پخش داخل سایت.
- پنل ابزارهای رایگان: افزودن، ویرایش و حذف لینک‌های دانلود HTTPS.
- کتابخانهٔ فایل‌های آپلودشده و پشتیبان ZIP شامل دیتابیس و رسانه‌ها.

## اجرا

Python 3.11 یا جدیدتر، بدون وابستگی خارجی:

```bash
python server.py init-admin
python server.py
```

در ویندوز فایل `start.bat` را اجرا کنید. نشانی فروشگاه روی همان دستگاه `http://127.0.0.1:8000` و پنل مدیریت `/admin` است.

رمز پیش‌فرض وجود ندارد. محصولات و قیمت‌های اولیه نمونه هستند؛ برای شروع فروش، محصولات واقعی، لوگوها و آدرس‌های عمومی کیف پول را در پنل تنظیم کنید. برای به‌روزرسانی، پوشهٔ `data` نصب خودتان را نگه دارید. این مخزن هیچ رمز، کیف پول واقعی یا پایگاه دادهٔ مشتری ندارد.

## آزمون‌ها

```bash
python -m unittest discover -s tests -v
```

۳۱ آزمون سرور و دو جریان مرورگر موفق بوده‌اند: ثبت سفارش و پرداخت دستی، و ساخت محصول با لوگوی آپلودشده، تغییر زندهٔ مبلغ، آپلود و پخش واقعی ویدیو و ثبت لینک ابزار رایگان. سرویس روی دامنهٔ عمومی منتشر نشده است؛ برای میزبانی عملیاتی، دیسک پایدار و HTTPS لازم است. در تنظیم وب‌سرور، سقف آپلود حداقل ۲۶۰ مگابایت باشد.

برای به‌روزرسانی، برنامهٔ قبلی را ببندید، فایل‌های تازه را جایگزین کنید و **کل پوشهٔ `data`** را نگه دارید. پس از اجرا صفحهٔ مدیریت را یک بار با Ctrl+F5 تازه کنید. فایل‌های شخصیِ آپلودشده در بستهٔ توزیع و GitHub قرار ندارند.
